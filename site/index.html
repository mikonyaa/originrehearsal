OriginRehearsal · v0.1.0

Does your upgrade keep existing users' data?

Rehearse web-app upgrades with retained browser profiles and explicit data contracts.

OLD application → real writes → full browser close → NEW application on the same origin and profile. A separate OLD cold control checks the seed and old startup behavior.

  1. OLD stores 20 synthetic notes and closes completely.
  2. BAD NEW reopens the same profile but retains only five notes.

  4. A separate clean BAD install saves a new note successfully.
  5. GOOD NEW preserves all 20 IDs and exact text, timestamps and note-to-tag links.
  6. The real GOOD report passes its upgrade contracts and separate OLD cold control.

The demo command's successful self-test never changes BAD's application report to PASS. The reports include actual origin, backend challenges, executed sentinels, profile identities, complete browser-close confirmations and OLD cold-control results.

Reproduce locally

npm install --ignore-scripts \
  https://github.com/mikonyaa/originrehearsal/releases/download/v0.1.0/originrehearsal-0.1.0.tgz
./node_modules/.bin/originrehearsal install-browser
./node_modules/.bin/originrehearsal demo --out ./artifacts/demo --no-open

Requires Node 24.21.0 or later Node 24 LTS and supported Chromium on macOS arm64 or Linux x64. The first browser download may take more than a minute. For a real app, prepare immutable static builds and meaningful seed/cold/upgrade contracts; see the integration guide.

Explicit scope

One http://127.0.0.1:<unchanged-port> gateway. Real isolated retained profiles. Selected localStorage keys and JSON-compatible IndexedDB data. Cache-Control: no-store cold updates. Service workers are detected and reported UNSUPPORTED, never blocked or cleared.

The application author defines legitimate transformation and deletion. This result does not establish universal preservation, production cache parity or external user validation. Reports contain selected data; these public examples use synthetic data only.

This static site shows recorded results. It does not run upgrades of visitors' applications.
